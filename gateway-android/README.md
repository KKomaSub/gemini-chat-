# Private MMS Gateway

전용 Android 휴대전화를 SMS/MMS 게이트웨이로 사용하는 개인용 앱입니다.

- 앱을 기본 SMS 앱으로 지정한 뒤 전송하므로 Android가 발신 SMS를 자동으로 SMS Provider에 기록하지 않습니다.
- 앱도 발신/수신 메시지 내용을 Telephony Provider나 자체 DB에 기록하지 않습니다.
- Reddit 이미지/동영상은 앱 메모리(byte[])에서만 받아 처리하며 갤러리/다운로드/캐시에 미디어 파일을 만들지 않습니다.
- 이미지는 메모리 안에서 1280x960 이하 JPEG로 축소하여 약 900KB 이하를 목표로 합니다.
- 동영상/오디오는 약 900KB 이하이면 MMS 첨부를 시도합니다. 통신사 MMS 정책이 거부하거나 더 큰 파일이면 원본 링크 문자로 폴백합니다.
- 기본 SMS 앱 역할 때문에 이 앱은 수신 SMS/MMS도 로컬 문자 DB에 저장하지 않습니다. 전용 게이트웨이폰 사용을 전제로 합니다.

설치 후 Android 시스템이 띄우는 기본 SMS 앱 지정과 문자 권한 허용만 하면 됩니다. 서버 주소나 전화번호를 입력하는 설정 화면은 없습니다.
