# 구형 Private MMS Gateway (비활성)

이 프로젝트는 과거 보조 휴대전화로 SMS/MMS를 전송하기 위해 작성된 실험용 앱입니다. **현재 Gmail → Reddit → SOLAPI 경로에서는 사용하지 않습니다.**

- 사용자의 삼성 기본 메시지 앱을 변경할 필요가 없습니다.
- Reddit `rN결과`는 Cloudflare에서 **이미지 여부만 확인**하고, 200KB 이하 JPEG를 SOLAPI MMS로 직접 전송합니다.
- 동영상/오디오 첨부 및 대용량 파일 링크 폴백 기능은 제거했습니다.
- 구형 게이트웨이 소스에도 이미지 외 미디어 거부와 200KB 상한을 적용했습니다.

**새로 설치하지 마세요.** 이전에 설치했다면 일반 문자 앱을 계속 쓰도록 기본 SMS 앱을 삼성 메시지로 되돌리고, 이 게이트웨이 앱은 제거해도 됩니다.
